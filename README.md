# 科技股长期估值与经营效率看板

公开的 GitHub Pages 版本，覆盖 31 家 A 股与全球科技公司，并支持本机个性化观察池。

## 在线访问

https://13760895561-cpu.github.io/ken-tech-valuation-dashboard/

## 数据更新

- 页面打开后直接从腾讯行情与 Frankfurter 汇率获取实时数据。
- 页面打开期间每 5 分钟自动检查一次。
- “立即更新”可由访客手动触发，并带 60 秒客户端保护。
- GitHub Actions 在工作日保存一份共享快照，持续积累历史记录。
- GitHub Actions 每天 07:17（上海时间）检查一次最新完整年报；营收、利润、现金流、现金、负债必须来自同一报告日，且币种、数量级与官方报告域名均通过校验后才会替换，失败时保留最近一次正确值。
- 员工数不自动覆盖，继续使用最近一次人工核验值，避免把公司档案的当前人数误当作年报期人数。

## 观察池

- 默认 31 家公司可在当前浏览器中隐藏或恢复，共享原始数据与历史不会被删除。
- 新增公司采用单输入智能搜索，可按证券代码、中文名、英文名、全拼或拼音首字母匹配；全市场本地证券目录仅在打开新增页时载入。
- 可新增 A 股、港股、美股或其他市场公司；A/HK/US 自定义公司会自动补全最近完整年报财务、员工数和自身估值倍数，并每 24 小时复查一次。
- 自定义公司的结构化财务数据会标注报告期、币种、来源与完整度；上游失败时保留最近成功缓存，缺失值保持空白，不会按 0 推算。
- 自定义公司仍不自动进入可比组、模型合理市值、事件和历史统计，避免未经正式复核的数据污染默认研究样本。
- 三条访问线路的浏览器存储彼此独立，可通过 JSON 文件或同步码迁移相同设置。

## Excel 导出

- 顶部“导出 Excel”按钮会按当前完整观察池生成 9 个工作表，包含看板概览、核心指标、估值明细、可比组统计、事件跟踪、历史快照、来源审计、方法与公式和导出检查。
- 公司范围为未隐藏的默认公司加全部自定义公司；估值、事件和历史使用当前有效范围，同时记录导出时的搜索、分组和地区筛选条件。
- 各表最右侧均保留“单位与公式”注释列；缺失财务值保持空白，不会用 0 代替。
- 可比组按 A股、中国成熟锚、美股独立分块，展示逐家公司、P75、中位数、P25 与 PERCENTILE.INC 插值过程。
- 自定义公司有可靠自动财务时会一并导出公开行情、财务和派生倍数；缺失字段保持空白。
- 自定义公司的私人观察备注不会进入导出文件，证券代码等文本也会按安全文本写入，避免被表格软件误识别为公式。
- 工作簿组件仅在点击导出时载入；导出中、成功和失败状态会在按钮下方明确提示。

## 币种口径

- 行情、市值按报价币种及报价汇率换算。
- 营收、利润、现金流、现金和负债按财务报表币种及财务汇率换算。
- 腾讯、阿里巴巴的报价币种为港币，当前财务报表币种为人民币；两种口径不会混用。
