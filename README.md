# 科技股长期估值与经营效率看板

公开的 GitHub Pages 版本，覆盖 31 家 A 股与全球科技公司，并支持本机个性化观察池。

## 在线访问

https://13760895561-cpu.github.io/ken-tech-valuation-dashboard/

## 数据更新

- 页面打开后直接从腾讯行情与 Frankfurter 汇率获取实时数据。
- 页面打开期间每 5 分钟自动检查一次。
- “立即更新”可由访客手动触发，并带 60 秒客户端保护。
- GitHub Actions 在工作日保存一份共享快照，持续积累历史记录。
- GitHub Actions 每天 07:17（上海时间）检查一次最新完整年报；营收、利润、现金流、现金、负债必须来自同一报告日，且币种、数量级与官方报告域名均通过校验后才会替换，失败时保留最近一次正确值。
- 员工数不自动覆盖，继续使用最近一次人工核验值，避免把公司档案的当前人数误当作年报期人数。

## 观察池

- 默认 31 家公司可在当前浏览器中隐藏或恢复，共享原始数据与历史不会被删除。
- 可新增 A 股、港股、美股或其他市场公司；腾讯行情代码可用时会显示最新行情。
- 自定义公司只进入观察区，不会未经核验就参与可比公司、估值和历史统计。
- 三条访问线路的浏览器存储彼此独立，可通过 JSON 文件或同步码迁移相同设置。

## 币种口径

- 行情、市值按报价币种及报价汇率换算。
- 营收、利润、现金流、现金和负债按财务报表币种及财务汇率换算。
- 腾讯、阿里巴巴的报价币种为港币，当前财务报表币种为人民币；两种口径不会混用。
